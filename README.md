# 語音記錄

對麥克風說話 → 說完一句就換一行,記錄在畫面中間的記事紙上 → 複製或下載成 .txt,再貼給 Claude 整理成文字。

做法參考 `Voice_Test_Procedure` 的手機網頁版:純靜態網頁,語音辨識由瀏覽器提供(Chrome/Edge 送到 Google、Safari 送到 Apple),**需要網路**。

## 在電腦上試

```bash
python3 -m http.server 8766 --directory web
```

然後開 http://localhost:8766 (`localhost` 允許使用麥克風)。

## 手機上用

手機要用麥克風必須是 **HTTPS**,所以要發布到 GitHub Pages:把專案推上 GitHub,到 Settings → Pages → Source 選「GitHub Actions」,之後每次改 `web/` 並推到 `main` 就會自動發布(設定檔在 `.github/workflows/pages.yml`)。Pages 網站是公開的,但記錄只存在各裝置自己的瀏覽器裡,不會上傳。

## 功能

- **聆聽模式**:常開監聽(按「開始」後一直聽,按「停止」結束);電腦的「按住說話」(按住按鈕或空白鍵);手機的「點擊監聽」(點「開始」說一句,說完停頓自動結束,也可再點提早結束)。iPhone 預設用點擊監聽,而且每次辨識完會把句子**念出來**:iPhone 的 Safari 若收音之間沒有朗讀播放,第二次之後常常聽不到聲音(參考專案也是這樣運作)。iPhone 的「常開監聽」也照同樣的順序:聽到句子 → 念出來並等念完 → 等 0.9 秒 → 才再開麥克風;但 Safari 是否允許在沒有點按的情況下自動接著聽,要實測。
- **暫存欄**(記事紙下方):剛辨識到的一句先放在這裡,字不對可以直接改。按「增加」(或在欄位裡按 Enter)就存進內文;沒按的話,下一句辨識進來時會自動把這一句存進內文。你正在暫存欄裡編輯時(游標在欄位裡),新辨識到的句子會先排隊,欄位上方會顯示「還有 N 句等你改完」;按「增加」或點一下別處,排隊的句子才依序進來。複製、下載、新增記錄時也會一併帶上,不會漏掉最後一句。
- **刪除暫存欄**:辨識錯太多、不想改時,按暫存欄旁的「刪除」,或直接**說「刪除」**(整句話只有這兩個字才算指令),就把剛辨識的那一句整句丟掉重來。已經存進內文的不會動。說「刪除」時如果有排隊中的句子,刪的是最後排隊的那一句。
- **記事紙**:內文一句一行;也可以直接點進去修改或打字(手機也可用鍵盤上的麥克風聽寫)。
- **多份記錄**:下拉選單切換,「新增」建立新的一份(以建立時間命名),「刪除記錄」刪掉目前這份。
- **複製 / 下載**:下載的檔名是建立時間,例如 `2026-11-05_1430.txt`。
- **清除**:清空目前這份的內容(會先確認)。
- 重新整理網頁後內容還在;記錄存在各裝置自己的瀏覽器(localStorage),**手機和電腦不會同步**。清除瀏覽器資料會一併清掉,重要的內容請先下載。
- 網址後面加 `?debug`,「設定」裡會出現診斷紀錄,語音辨識有問題時可截圖。

## 注意

- 瀏覽器只給文字,**不會保存錄音檔**。
- 中文辨識結果通常沒有標點;數字有時是阿拉伯數字、有時是中文,同一句話也可能不一致,記得檢查。
- 語音辨識一次只能選一種語言,目前固定為 `zh-TW`,英文單字常被辨識錯。
